# Vision Board

A simple, responsive static website for setting and visualizing personal goals over a 90-day period.

## Main Features

- **90-day countdown:** Displays the time remaining, finish date, and current day of the plan.
- **Automatic rollover:** Starts a new 90-day cycle when the current cycle ends.
- **Three-phase plan:** Breaks the 90 days into starting, building consistency, and finishing phases.
- **Goal tracking:** Presents clear targets and actionable steps for each goal.
- **Responsive design:** Works on desktop and mobile devices.
- **Print support:** Allows the vision board to be printed.

## Technology

- HTML, CSS, and JavaScript
- Azure Static Web Apps for hosting
- Bicep for infrastructure as code
- GitHub Actions for automated deployment

No backend, database, or build tools are required.
